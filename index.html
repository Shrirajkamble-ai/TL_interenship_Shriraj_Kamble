VS Code — add repository & portfolio project

Step 1 — Create repository (GitHub) Sign in at github.com → New repository → name it (e.g. portfolio) → Public → Create repository
Step 2 — Open project in VS Code VS Code → File → Open Folder → select the portfolio folder Or: Terminal → New Terminal (Ctrl + `)
Step 3 — Initialize Git & connect remote In the VS Code terminal, inside portfolio: git init git remote add origin https://github.com/YOUR_USERNAME/portfolio.git UI: Source Control (Ctrl+Shift+G) → Initialize Repository → Add Remote
Step 4 — Stage & commit files git add . git commit -m "Add portfolio website" UI: Source Control → stage changes (+) → enter message → Commit
Step 5 — Push to GitHub git branch -M main git push -u origin main UI: Source Control → … → Push, or Publish Branch
